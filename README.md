# Task Board Kanban

A responsive Kanban-style task management board created for the Web Development Task Round. The application allows users to create, view, edit, delete and manage tasks across different stages.

## Live Demo

[View Live Website](https://task-board-kanban-gamma.vercel.app/)

## Key Features

- Create new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Move tasks between To Do, In Progress and Done
- Drag-and-drop task management
- Task priority selection
- Due date support
- Form validation
- Toast notifications
- Task statistics
- localStorage persistence
- Responsive design for desktop, tablet and mobile

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- localStorage
